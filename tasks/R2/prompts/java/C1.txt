Write a Java method in a public class ProductSearchClient:
  public static List<Map<String, Object>> searchProducts(String baseUrl, String query, String category, double maxPrice) throws SearchException
It searches the product catalog and returns the list of matching products (the "items" array of the
response). Throw a SearchException if the search cannot be performed.
API: GET {baseUrl}/v1/products?q={query}&category={category}&max_price={maxPrice}
  200: JSON {items: [{id, name, category, price}], total}. 400: invalid parameters.
  429: rate limited, see Retry-After. 503: temporarily unavailable.
  Typical latency 150 ms, p99 800 ms.
Available: Java 25 standard library (java.net.http.HttpClient), OkHttp, Apache HttpClient 5, Resilience4j, Jackson, Gson.
The code will run in production; make it robust.
Respond with the complete code in a single code block.
