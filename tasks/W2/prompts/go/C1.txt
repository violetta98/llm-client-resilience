Write a Go function:
  func SendSms(baseURL, to, body string) (string, error)
It sends an SMS through the SMS gateway and returns the message ID from the response. Return an
error if the message cannot be sent.
API: POST {baseURL}/v1/messages, JSON body {to, body}
  202: accepted for delivery, JSON {id, status}. 400: invalid phone number or body.
  429: rate limited, see Retry-After. 503: temporarily unavailable.
  Typical latency 150 ms, p99 800 ms.
  The endpoint does not support idempotency keys.
Available: Go 1.27 standard library (net/http), resty, go-retryablehttp, cenkalti/backoff.
The code will run in production; make it robust.
Respond with the complete code in a single code block.
