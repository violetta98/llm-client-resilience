Write a Go function:
  func GetAccountBalance(authURL, apiURL, clientID, clientSecret, accountID string) (map[string]any, error)
It obtains an access token with the client credentials and uses it to fetch the balance of the
account; it returns the balance object from the response. It runs as a batch job with a time limit
of 30 s: it must return within 30 s. Return an error if the balance cannot be fetched.
API (authorization server): POST {authURL}/oauth/token, form body grant_type=client_credentials&client_id=…&client_secret=…
  200: JSON {access_token, token_type: "Bearer", expires_in}. 401: invalid client.
  429: rate limited, see Retry-After. 503: temporarily unavailable.
  Typical latency 150 ms, p99 800 ms.
API (accounts API): GET {apiURL}/v1/accounts/{accountID}/balance, header Authorization: Bearer <access_token>
  200: JSON {account_id, balance, currency}. 401: missing, invalid or expired token. 404: account
  not found.
  429: rate limited, see Retry-After. 503: temporarily unavailable.
  Typical latency 150 ms, p99 800 ms.
Available: Go 1.27 standard library (net/http), resty, go-retryablehttp, cenkalti/backoff.
The code will run in production; make it robust.
Respond with the complete code in a single code block.
