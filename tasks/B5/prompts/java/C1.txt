Write a Java method in a public class ShipmentUpdatesClient:
  public static List<Map<String, Object>> fetchShipmentUpdates(String baseUrl, String carrierId, String since) throws ShipmentUpdatesException
It fetches the shipment status updates that the carrier reported after since (an RFC 3339 time) and
returns the list of updates (the "updates" array of the response). It runs as a nightly batch job
with a time limit of 30 s: it must return or throw within 30 s. Throw a ShipmentUpdatesException if
the updates cannot be fetched.
API: GET {baseUrl}/v1/carriers/{carrierId}/shipment-updates?since={since}
  200: JSON {updates: [{shipment_id, status, updated_at}], next_since}; updates are ordered by
  updated_at, at most 100 per response; next_since is the updated_at of the last update. 400:
  invalid since. 404: carrier not found.
  429: rate limited, see Retry-After. 503: temporarily unavailable.
  Typical latency 150 ms, p99 800 ms.
Available: Java 25 standard library (java.net.http.HttpClient), OkHttp, Apache HttpClient 5, Resilience4j, Jackson, Gson.
The code will run in production; make it robust.
Respond with the complete code in a single code block.
