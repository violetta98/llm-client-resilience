Write a Go function:
  func GetExchangeRate(baseURL, baseCurrency, quoteCurrency string) (map[string]any, error)
It fetches the current exchange rate for the currency pair from the rates service and returns the
rate object from the response. Return an error if the rate cannot be fetched.
API: GET {baseURL}/v1/rates/{baseCurrency}/{quoteCurrency}
  200: JSON {base, quote, rate, as_of}. 404: unknown currency pair.
  429: rate limited, see Retry-After. 503: temporarily unavailable.
  Typical latency 150 ms, p99 800 ms.
Available: Go 1.27 standard library (net/http), resty, go-retryablehttp, cenkalti/backoff.
Requirements:
- Every call of the function finishes within the stated time limit, or within 10 s if none is stated.
- Transient failures are retried with capped exponential backoff and jitter.
- Retry-After is respected.
- Writes are not repeated without an idempotency key.
Respond with the complete code in a single code block.
