Write a Java method in a public class TicketClient:
  public static String addTicketComment(String baseUrl, String ticketId, String text) throws CommentException
It adds the comment text to the support ticket and returns the comment ID from the response. Throw a
CommentException if the comment cannot be added.
API: POST {baseUrl}/v1/tickets/{ticketId}/comments, JSON body {text}
  201: comment added, JSON {id, ticket_id, created_at}. 400: empty text. 404: ticket not found.
  429: rate limited, see Retry-After. 503: temporarily unavailable.
  Typical latency 150 ms, p99 800 ms.
  The endpoint does not support idempotency keys.
Available: Java 25 standard library (java.net.http.HttpClient), OkHttp, Apache HttpClient 5, Resilience4j, Jackson, Gson.
Respond with the complete code in a single code block.
